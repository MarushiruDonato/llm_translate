# LLM 划词翻译 — 冒烟测试清单 (Smoke Test Checklist)

## 1. 扩展安装与基本加载
- [ ] 在 `chrome://extensions/` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择 `.output/chrome-mv3` 目录。
- [ ] 扩展成功加载，图标清晰正常（16、48、128 三规格完整呈现），无任何红色报错或警告。
- [ ] 点击工具栏扩展图标，弹出 Popup 窗口，展示「暂无翻译历史」空状态、全局开关、设置入口与搜索栏。

## 2. Options 配置档与权限申请
- [ ] 点击 Popup 右上角齿轮图标，成功进入 Options 设置页。
- [ ] 在「模型配置档」Tab 中，编辑默认配置档，填入合法的 API Key（如 DeepSeek 或 OpenAI）与 Base URL。
- [ ] 点击「保存配置并授权」：
  - 验证：浏览器立即弹出原生权限授权弹窗（如提示“访问来自 api.deepseek.com 的数据”）。
  - 点击「允许」：页面提示保存成功与授权完成。
  - 测试「拒绝」路径：新建一个配置档并故意点击拒绝，验证页面弹出错误提示且不破坏原有可用配置。
- [ ] 点击「测试连接」按钮：
  - 验证：端点发出测试翻译，成功返回预期文本并提示绿色连通成功。

## 3. 网页划词触发与卡片交互
- [ ] 打开任意英文网页（如 Wikipedia 或 GitHub 文档）：
  - 鼠标划选一段文字。
  - 选区右上方立即出现小巧的蓝色翻译按钮。
  - 点击翻译按钮，就地平滑展开悬浮翻译卡片。
  - 卡片顶部显示源语言标签（如 `源: EN`），内容区以打字机形式逐字流式渲染中文译文。
- [ ] 复制功能验证：
  - 点击卡片底部的「复制」按钮，按钮短暂切换为「已复制 ✓」，到文本编辑器中粘贴确认译文内容准确无误。
- [ ] 拖拽与钉住验证：
  - 鼠标按住卡片顶部栏可自由拖动卡片至屏幕任意位置。
  - 点击卡片顶部图钉图标开启「固定」，点击卡片外部区域，卡片不会被误关闭。
  - 再次点击图钉取消固定，点击卡片外侧或按下 `Esc` 键，卡片顺利关闭。
- [ ] 重复翻译与缓存命中：
  - 再次划选刚才完全相同的英文段落，点击翻译按钮。
  - 验证：卡片底部瞬间点亮「⚡ 缓存命中」标签，译文秒级直接呈现，无需等待网络。
  - 点击卡片底部的「重试」按钮，验证其强制绕过缓存，重新向后端发起流式请求。

## 4. 多触发方式验证
- [ ] 右键菜单触发：
  - 划选一段文字，右键点击「翻译所选内容」。
  - 验证：无需点击小按钮，就地直接呼出悬浮卡片并开始流式翻译。
- [ ] 快捷键触发：
  - 划选一段文字，按下快捷键 `Alt+T`。
  - 验证：当前网页焦点处的选区就地展开卡片并翻译。
- [ ] 跨 iframe 兼容测试：
  - 在包含嵌入 iframe 的网页（如文档站、CodePen 等）中，划选 iframe 内的文字，测试右键菜单与快捷键触发是否正确定位在 iframe 内部选区旁。

## 5. Popup 历史与全局开关
- [ ] 点击工具栏扩展图标打开 Popup：
  - 刚刚翻译的记录倒序排列在历史列表中，显示原文、译文、模型标签与时间。
  - 在搜索栏输入关键字，列表即时过滤匹配记录。
  - 点击单条记录底部的「复制」，快速复制译文。
- [ ] 全局开关：
  - 在 Popup 顶部切换关闭总开关（滑块变为灰色），页面顶部出现暂停提示条。
  - 回到网页划选文字，验证不再弹出翻译按钮，右键与快捷键静默不触发。
  - 在 Popup 中重新打开总开关，网页划词翻译功能立即恢复。

## 6. 异常与边界场景
- [ ] 划选超过 5000 字符的长篇文本，验证卡片给出友好的字符上限提示，不崩溃不发无谓请求。
- [ ] 填入错误的 API Key，发起翻译，卡片呈现红色错误提示，并根据可重试状态展示重试按钮。
